# Basic PDF

PDF를 읽고, 주석을 달고, 서명하고, 페이지를 정리하는 PDF 리더·편집기입니다.
Windows 앱과 웹 버전이 있고, 두 버전 모두 파일을 서버로 보내지 않고 내 컴퓨터(브라우저) 안에서만 처리합니다.

A PDF reader and editor for Windows and the web. Files never leave your device.

## 웹에서 바로 쓰기

**https://lussion629-creator.github.io/basic-pdf/**

설치 없이 브라우저에서 열립니다. 크롬·엣지에서는 연 파일에 바로 덮어써 저장할 수 있고, 다른 브라우저에서는 저장할 때 파일이 내려받아집니다.

## Windows 앱 설치 (인터넷 연결 필요 없음)

1. [Releases](../../releases/latest)에서 파일 4개(`Basic-PDF-오프라인설치.zip`, `data.002`, `data.003`, `data.004`)를 받아 같은 폴더(보통 다운로드 폴더)에 둡니다.
2. `Basic-PDF-오프라인설치.zip`의 압축을 풉니다.
3. 압축 푼 폴더에서 `설치.bat`을 더블클릭합니다. 서명이 없는 파일이라 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다.
4. 설치가 끝나면 앱이 열리고 바탕화면과 시작 메뉴에 아이콘이 생깁니다.

설치 위치: `%LOCALAPPDATA%\Programs\Basic PDF`
제거: 설치 폴더의 `제거.bat`

## 기능

- **읽기**: 탭으로 여러 문서 열기, 페이지 썸네일·책갈피·주석 목록, 찾기, 단일/연속/두 페이지 보기, 회전, 읽기 모드
- **주석**: 텍스트 강조·밑줄·취소선, 메모, 펜, 사각형·타원·선·화살표, 텍스트 상자, 스탬프
- **PDF 편집**: 기존 텍스트를 클릭해서 고치기, 이미지 넣기, 화이트아웃
- **서명**: 직접 그리기 / 이름 입력 / 이미지로 만들어 넣기 (암호화해 보관)
- **양식 채우기**: PDF 입력 칸에 바로 입력
- **페이지 구성**: 끌어서 순서 바꾸기, 회전, 삭제, 빈 페이지·다른 PDF 삽입, 추출, 분할
- **그 밖에**: 파일 결합, 페이지 번호, 워터마크, PNG·텍스트 내보내기, 인쇄, 문서 속성
- **테마**: 밝게 / 어둡게 / 시스템 설정, 페이지까지 어둡게 보는 야간 읽기

## 보안과 개인 정보

- 문서와 서명을 서버로 보내지 않습니다. 앱과 웹 버전 모두 외부로 나가는 네트워크 요청을 차단합니다(PDF 안의 외부 주소 포함).
- PDF 안의 스크립트(JavaScript)는 실행하지 않습니다.
- Windows 앱: 사용자가 직접 열거나 저장 위치로 고른 파일에만 접근하고, 문서 화면은 샌드박스에서 실행합니다. 서명은 Windows 계정으로 암호화(DPAPI)해 보관합니다. 실행 파일 변조·디버거 연결을 막는 Electron 퓨즈를 켰습니다.
- 웹 버전: 서명은 브라우저 안에서 AES-GCM으로 암호화하고, 키는 꺼낼 수 없는 형태로 보관합니다.
- 편집 메뉴(웹은 ☰ 메뉴)의 **개인 정보 지우기**로 서명·최근 파일 목록·작성자 이름을 한 번에 지울 수 있습니다.
- 화이트아웃은 보이는 부분만 가립니다. 원래 텍스트는 파일에 남으므로 민감한 정보 삭제용으로 쓰지 마세요.

## 직접 빌드하기

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start               # 데스크톱 앱 실행 (개발용)
npm run build:web       # 웹 버전 → docs/
npm run build:win       # Windows 오프라인 설치본 → dist/release/
```

| 폴더 | 내용 |
| --- | --- |
| `app/` | 앱 본체 (Electron 메인 프로세스와 화면) |
| `web/` | 웹 버전에서 데스크톱 기능을 대신하는 계층, 웹용 한글 글꼴 |
| `docs/` | 빌드된 웹 버전 (GitHub Pages가 이 폴더를 게시) |
| `build/` | 웹·Windows 빌드 스크립트, 설치 스크립트, 아이콘 |
| `test/` | 자동 테스트 (데스크톱: `run.js`, 웹: `web-test.js`) |
