Basic PDF — 사용 안내

[이름 변경]
- Paperline PDF의 새 이름입니다. 이전 버전이 설치되어 있으면 설치할 때 자동으로 정리되고,
  저장해 둔 서명·설정·최근 파일 목록은 처음 실행할 때 그대로 옮겨집니다.

[실행]
- 바탕화면이나 시작 메뉴의 Basic PDF 아이콘으로 실행하세요. 인터넷 연결은 필요 없습니다.
- PDF를 기본 앱으로 쓰려면: PDF 우클릭 → 연결 프로그램 → 다른 앱 선택 → Basic PDF → "항상" 체크.
- 지우려면 설치 폴더의 "제거.bat"을 실행하세요.

[주요 기능]
- 읽기: 탭으로 여러 문서 열기, 썸네일·책갈피·주석 목록, 찾기(Ctrl+F), 단일/연속/두 페이지 보기, 회전, 읽기 모드(Ctrl+H)
- 주석: 텍스트 강조·밑줄·취소선, 메모, 펜, 사각형·타원·선·화살표, 텍스트 상자, 스탬프
- PDF 편집: 기존 텍스트를 클릭해서 고치기, 이미지 넣기, 화이트아웃
- 서명: 직접 그리기 / 이름 입력 / 이미지로 서명 만들어 넣기 (서명은 PC에 저장되어 다시 쓸 수 있음)
- 양식 채우기: PDF 입력 칸에 바로 입력
- 페이지 구성: 끌어서 순서 변경, 회전, 삭제, 빈 페이지·다른 PDF 삽입, 추출, 분할
- 파일 결합, 페이지 번호, 워터마크, PNG/텍스트 내보내기, 인쇄, 문서 속성 편집
- 다크 모드: 도구 모음의 해/달 버튼 → 밝게 / 어둡게 / 시스템 설정 따르기 (Ctrl+Shift+L)
  야간 읽기: 같은 메뉴에서 "페이지도 어둡게" (Ctrl+Shift+N). 화면 표시만 바뀌고 저장·인쇄는 원래 색 그대로입니다.

[알아 둘 점]
- 저장하면 주석·서명·도형이 페이지에 합쳐져 저장됩니다(메모는 표준 PDF 메모로 저장되어 다른 PDF 프로그램에서도 보입니다).
  편집 중에는 언제든 고치거나 실행 취소할 수 있습니다.
- 한글 글자는 Windows의 맑은 고딕 글꼴을 문서에 넣어 저장합니다.
- "PDF 편집"으로 고친 줄은 원래 글자를 흰색으로 덮고 새 글자를 얹는 방식이라 글꼴이 원본과 조금 다를 수 있습니다.
- 화이트아웃은 보이는 부분만 가립니다. 원래 텍스트는 파일 안에 남으므로 민감한 정보 삭제용으로는 쓰지 마세요.
- 편집 제한(암호화)이 걸린 PDF는 페이지를 이미지로 바꾼 새 PDF로만 저장할 수 있습니다.

[단축키] 도움말 메뉴 → 단축키 (F1)
